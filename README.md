# HackAlem 4.0 · два AI-агента и подбор команд

Бизнес превращает запрос в подтверждённую задачу, студенты находят проекты по навыкам, бизнес вручную выбирает исполнителей.

Python 3.9+, SQLite, HTML/CSS/JavaScript. Без pip/npm-зависимостей и сборки. Node нужен только для тестов фильтрации.


## Проверка организаторами — без установки и личных аккаунтов

**Сайт: https://hackalem-cloud.onrender.com**

Это облачный сервер: ноутбук команды и интернет в месте проведения не нужны. После простоя бесплатный сервер может запускаться 50–90 секунд; дождитесь загрузки страницы.

| Демо-роль | Логин | Пароль |
|---|---|---|
| Бизнес | `business@demo.local` | `hackalem2026` |
| Студенческая команда | `student@demo.local` | `hackalem2026` |

Это тестовые аккаунты проекта, а не личные аккаунты участников. Проверяющему не нужны аккаунты GitHub/OpenAI/Render, подписки или собственный API-ключ. ИИ подключён на сервере через демонстрационный доступ команды; секрет отсутствует в репозитории и браузере.

**Проверка ключевых функций:**
1. Войти как бизнес, открыть «Создать задачу», вставить описание компании и задачи.
2. Первый агент извлекает 10 полей; проверить и дополнить их, затем сохранить и оценить.
3. Подтвердить карточку: второй агент задаст 3–5 индивидуальных вопросов, затем предложит направления, специалистов и навыки. Источники исследования компании показаны в интерфейсе.
4. Подтвердить требования и опубликовать задачу. Выйти, войти как студент, найти задачу и отправить отклик.
5. Войти как бизнес, просмотреть отклики и выбрать команду. Проверить профили, фильтры и объяснение совместимости.

Подробности: [docs/TWO_AGENT_WORKFLOW.md](docs/TWO_AGENT_WORKFLOW.md). Если внешний API недоступен, интерфейс явно показывает ограниченный локальный режим; это не полноценная замена LLM.

**Ограничение бесплатного демо:** SQLite на Render Free не является постоянным хранилищем. После перезапуска облачного экземпляра созданные во время проверки записи могут сброситься; исходные тестовые аккаунты и демо-набор создаются заново. Используйте синтетические данные.

## Локальный запуск (не требуется организаторам)

```bash
python3 server.py --port 8001
```

Откройте http://127.0.0.1:8001. Первый запуск создаёт `data/hackalem.sqlite3`: **29 опубликованных задач, 11 черновиков, 15 команд, 77 откликов и 21 аккаунт**. Демо-данные синтетические. SQLite сохраняет изменения и переписку. Обновление существующей базы добавочное, без сброса. Не удаляйте `.env` и `data/`; инструкция: [UPDATE.md](UPDATE.md).

## Возможности

- Два агента: извлечение и оценка 10 полей без вопросов; исследование компании и 3–5 уточнений после подтверждения карточки; затем предложения специалистов и навыков. Подробности — в docs/TWO_AGENT_WORKFLOW.md.
- Рекомендации навыков: бизнес выбирает требования и важность ×1/×2/×3. Для синтетических задач требования уже согласованы.
- Персональная совместимость 0–100 для каждой пары задача–команда с объяснением совпадений и пробелов. Она не является оценкой личности или гарантией квалификации.
- Кросс-фильтры каталога: несколько тематик, навыков, уровней готовности, форматов, даты, минимумы готовности/совместимости, неистёкший срок. Для навыков — «хотя бы один»/«все». Счётчики учитывают остальные фильтры.
- Компактный раздел команд: раскрываемые отклики и соседняя вкладка подбора. План, профиль, решение и подтверждение этапа собраны вместе, повторные списки удалены.
- Подробный профиль: собственное описание, навыки, университет, обучение, состав, опыт и доступность. Для демо заранее сформированы AI-саммари; из своего профиля их можно обновить подключённой моделью. При изменении профиля показывается сводка по правилам до нового AI-анализа.
- Импорт публичных GitHub-репозиториев по URL. LinkedIn — ссылка и вставленный текст либо TXT/CSV/JSON; обход закрытых страниц не используется. Импорт требует согласия и подтверждения извлечённых сведений.
- Постоянный ассистент на страницах: переписка аккаунта, контекст открытой задачи, общие вопросы и медиа.
- 6 учебных отраслевых CSV по 300 строк, всего 1800 строк, в `static/demo-data/`. Ссылки есть в демо-карточках. Это отраслевые примеры, не полные материалы для каждого отдельного проекта.
- Обязательный сценарий ТЗ сохранён: любой рейтинг допускает публикацию и отклик, отклики не ограничены, бизнес выбирает одну/несколько/ни одной команды, за подтверждённый этап +10 ровно один раз.

## ИИ

Скопируйте `.env.example` в `.env` рядом с `server.py` и задайте:

```dotenv
AI_MODE=auto
AI_API_KEY=ваш_ключ
AI_MODEL=gpt-4.1-mini
AI_BASE_URL=https://api.openai.com/v1
AI_TIMEOUT_SECONDS=30
AI_TRANSCRIBE_MODEL=gpt-4o-mini-transcribe
```

Перезапустите сервер. Реальный ключ остаётся только в `.env`, который исключён из Git. Переменные окружения имеют приоритет. Полноценный свободный диалог требует доступной модели; при сбое работает подписанный локальный резерв. `/api/health` сообщает конфигурацию, а успешный ответ модели определяется по `mode: remote`. Ассистент отвечает, но не выполняет изменения от имени пользователя.

Фото JPEG/PNG/WebP до 8 МБ уменьшаются в браузере. Видео до 40 МБ и 2 минут анализируется как **6 кадров без звука**. Аудио MP3/M4A/WAV/WebM/OGG/FLAC до 5 МБ отправляется в распознавание речи. За сообщение — до 3 файлов, 8 изображений/кадров и одного аудио. Нужна модель с поддержкой изображений и доступный audio/transcriptions. Неудачная обработка явно отмечается; локальный режим не изображает понимание медиа.

Исходные файлы в базе не сохраняются. Остаются текст, метаданные, ответы и расшифровки. Повторные сообщения используют текстовую историю; прошлые кадры не пересылаются повторно. Диалог конструктора: до 200 сообщений / 100 000 символов. Общий ассистент: до 200 сообщений / 150 000 символов, затем можно начать новый диалог.

## Публичное демо

Оставьте существующий Cloudflare-туннель на 127.0.0.1:8001 и перезапустите только приложение:

```bash
python3 server.py --port 8001 --public-origin https://ВАША-ТЕКУЩАЯ-ССЫЛКА.trycloudflare.com
```

Адрес должен точно совпадать с текущим туннелем. Обновите браузер Cmd+Shift+R. Компьютер, сервер и туннель должны оставаться включёнными. Для хостинга поддерживаются HOST, PORT, DATABASE_PATH, PUBLIC_ORIGIN; нужен постоянный диск SQLite и одна реплика. Dockerfile использует `/data`.

## Формулы

Готовность: контекст 10 + потребность 10 + данные 20 + результат 15 + критерии 15 + ограничения 10 + пользователи 10 + контакт 5 + взаимодействие 5. Только содержательные подтверждённые поля. Уровни 0–39 / 40–69 / 70–89 / 90–100.

Совместимость: `round(100 × вес совпавших навыков / вес подтверждённых требований)`. Университет, состав команды, возраст и популярность GitHub не влияют на оценку. Отрасль объясняется отдельно, без скрытых баллов. При отсутствии требований — «нет оценки».
