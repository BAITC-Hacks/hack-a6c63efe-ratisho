# HackAlem 2.0 · AI Studio + Matching

MVP для AI Sana / HackAlem: бизнес превращает запрос в подтверждённую задачу, студенты находят задачи по навыкам, бизнес вручную выбирает исполнителей.

**Python 3.9+, SQLite, HTML/CSS/JavaScript. Без pip/npm-зависимостей и сборки.** Node нужен только для дополнительных тестов фильтрации.

## Запуск

```bash
python3 server.py --port 8001
```

Откройте http://127.0.0.1:8001. На Windows можно использовать `py server.py --port 8001`.
Первый запуск создаёт `data/hackalem.sqlite3`: 5 опубликованных задач, 5 черновиков, 5 команд, 5 откликов. Все демоданные синтетические. SQLite сохраняет задачи, диалоги, навыки, подтверждённые профили и историю рейтинга.

**Обновление существующего проекта: сначала [UPDATE.md](UPDATE.md). Не удаляйте `.env` и базу в `data/`.**

## Что нового

- Переписка на шаге уточнения: постоянная история, память фактов с источниками, адаптивные вопросы с моделью, возможность исправлять ответы. Переписка отдельная для каждой задачи.
- Автоматические предложения навыков при сборке карточки; бизнес выбирает навыки и важность ×1 / ×2 / ×3. Есть повторный анализ и ручной ввод.
- Персональная совместимость 0–100 для каждой пары «задача — профиль», объяснение совпадений и недостающих навыков. Один профиль получает разные оценки для разных задач. Это не оценка личности или гарантия квалификации.
- Каталог: совместные фильтры по тематике, навыкам, уровню, минимуму рейтинга/совместимости, датам создания, формату и неистёкшему сроку. Счётчики отражают остальные активные фильтры. Можно выбрать несколько значений, для навыков доступны «хотя бы один» и «все».
- Импорт публичных оригинальных репозиториев GitHub по URL/username без токена. LinkedIn — ссылка на источник + вставка текста или TXT/CSV/JSON. Импорт создаёт черновик; навыки и достижения сохраняются после проверки человеком. Прямой обход закрытых LinkedIn-страниц не реализован.
- Бизнес видит подходящие профили, обоснование, достижения с источниками и таблицу сравнения откликов. Студент видит персональную подборку в профиле и совместимость на карточках.
- Проверка возможных противоречий, следующий шаг для повышения рейтинга, история готовности, фактические этапы работы агентов, отдельный сбрасываемый учебный пример.
- Обязательный сценарий ТЗ сохранён: редактирование и подтверждение карточки, каталог, неограниченные отклики, ручной выбор нескольких команд, +10 за подтверждённый этап ровно один раз.

## Настройка ИИ

Скопируйте `.env.example` в `.env` рядом с `server.py` и задайте:

```dotenv
AI_MODE=auto
AI_API_KEY=ваш_ключ
AI_MODEL=gpt-4.1-mini
AI_BASE_URL=https://api.openai.com/v1
AI_TIMEOUT_SECONDS=30
```

Перезапустите сервер. Ключ остаётся на сервере, `.env` исключён из Git. Конфигурация берётся из `.env`; уже установленные переменные окружения имеют приоритет. Для другого совместимого провайдера поменяйте URL, модель и ключ. Для Ollama разрешён HTTP только localhost, но совместимость конкретной модели нужно проверить самостоятельно.

**Для полноценного свободного разговора нужна работающая языковая модель.** Без неё работает честно обозначенный локальный режим: диалог по правилам, ручной выбор поля ответа, извлечение навыков по словарю, прозрачный подбор. Он не заменяет LLM.

При ошибке API/тайм-ауте/некорректном JSON используется локальный резерв с предупреждением. Фактический режим видно на ответе/панели агентов. `/api/health` сообщает о конфигурации, но не подтверждает успешный запрос. Проверяйте фактический ответ и расход в кабинете провайдера. API-ключ в сборку не включён.

## Публичное демо через имеющийся туннель

Если Cloudflare уже направляет запросы на `127.0.0.1:8001`, оставьте его работать и перезапустите только приложение:

```bash
python3 server.py --port 8001 --public-origin https://ВАША-ТЕКУЩАЯ-ССЫЛКА.trycloudflare.com
```

Вставьте адрес обычным текстом. Он должен точно совпадать с адресом туннеля. Обновите браузер через Cmd+Shift+R. Компьютер, сервер и туннель должны работать всё время показа. Не запускайте второй сервер на занятом порту.

Для обычного хостинга поддерживаются `HOST`, `PORT`, `DATABASE_PATH`, `PUBLIC_ORIGIN`. Приложение использует SQLite: нужен постоянный диск и одна реплика. `Dockerfile` запускает Python на `0.0.0.0`; mount `/data`. `PUBLIC_ORIGIN` — точный HTTPS-адрес вашего сайта. Для Railway поддерживается `RAILWAY_PUBLIC_DOMAIN`, для Render — `RENDER_EXTERNAL_URL`.

## Рейтинг и подбор

**Готовность бизнес-задачи:** контекст и потребность 20, данные 20, результат 15, критерии успеха 15, ограничения 10, пользователи 10, контакт и взаимодействие 10. Баллы только за содержательные и подтверждённые поля. Уровни: 0–39 / 40–69 / 70–89 / 90–100. Пустые и неподтверждённые поля дают 0. Изменения требуют нового подтверждения.

**Совместимость:** `round(100 × вес совпавших навыков / вес всех подтверждённых требований)`. Сопоставление использует нормализованные названия и словарь синонимов. Если требований нет, показывается «нет оценки», а не 0. GitHub-популярность, фотографии, возраст и другие чувствительные признаки не входят в формулу. Совпадение отрасли объясняется отдельно и не даёт скрытых баллов. Неизвестные навыки считаются пробелом профиля, а не доказательством неспособности.

**Каталог:** общий, без закрытого доступа по рейтингу. По умолчанию сортировка по готовности. Студент может выбрать сортировку по совместимости, сочетать её с порогом готовности или датой. Рекомендации не назначают команды. Баллы за реальные этапы — отдельная величина, +10 после подтверждения бизнеса.

## Архитектура

- `server.py`: HTTP/API, ограничения запросов, роли, проверка Origin, конфигурация.
- `app/store.py`: SQLite, версии записей, ручные подтверждения, история, диалоги и профили.
- `app/agents.py`: базовые Analysis / Interview / Composition / Validation и серверный клиент провайдера.
- `app/intelligence.py`: Conversation, Skills и Review; сохранённая история и проверка цитат.
- `app/profiles.py`: публичный GitHub, предварительный профиль, извлечение по источникам.
- `app/matching.py`: формула совместимости и объяснения.
- `static/catalog.js`: независимая проверяемая логика перекрёстных фильтров.
- `static/app.js`, `styles.css`: интерфейс без зависимостей.

## Границы демо

Переключатель ролей предназначен для хакатона: **это не авторизация**. Любой посетитель демо может переключить роль, редактировать задачи и выбранный профиль. Используйте синтетические/разрешённые данные. До эксплуатации с реальными участниками нужны вход пользователей, проверка владельца, изоляция организаций, контроль расходов API, ограничения запросов и резервное копирование. В этой версии кандидат — профиль участника/команды; отдельные учётные записи и объединение нескольких участников в одну команду не реализованы.

Полная история сохраняется до 200 сообщений / 100 000 символов на задачу; при достижении лимита предложено собрать карточку, данные не удаляются. GitHub: до 12 оригинальных репозиториев из 100 недавно обновлённых, кеш на час, тайм-ауты и обработка лимитов. Просмотр репозитория не доказывает авторство всех работ или уровень владения технологией. Саммари содержит выбранные участником выдержки, а не независимую проверку достижений.
