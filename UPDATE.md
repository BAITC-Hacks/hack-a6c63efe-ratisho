# Как обновить ваш работающий сайт

1. Сделайте резервную копию текущей папки `hackalem`.
2. Остановите **только сервер Python** через Ctrl+C в его окне. Окно Cloudflare оставьте открытым.
3. Распакуйте новый архив. Перенесите из новой папки `hackalem` в вашу текущую папку **содержимое**, заменяя `server.py`, папки `app`, `static`, `tests`, `docs` и остальные файлы исходников. Перенесите также `.github`, `.gitignore`, `.env.example`. Папку `.git` вашего репозитория сохраняйте.
4. **Сохраните ваш `.env` и папку `data` с базой.** Не заменяйте их пустыми файлами и не удаляйте старую папку проекта целиком. В архиве нет ключа и пользовательской базы. Формат прежней SQLite-базы совместим, новые сведения появятся при использовании функций.
5. В текущей папке проекта запустите:

```bash
python3 server.py --port 8001 --public-origin https://downloadable-there-okay-mitsubishi.trycloudflare.com
```

Используйте этот адрес только если он всё ещё показан в работающем окне Cloudflare. Если туннель перезапускали, замените адрес новым.

6. Откройте сайт и нажмите **Cmd+Shift+R**. В меню появятся «Мой профиль» (роль Команда) и «Репетиция демо».
7. Для старых задач откройте редактирование → «Предложить навыки» → подтвердите нужные. Старую базу программа не заполняет искусственными требованиями автоматически. У новых карточек навыки предлагаются при сборке.
8. Проверьте `.env`: `AI_MODE=auto`, непустые `AI_API_KEY` и `AI_MODEL`. При исправлении настроек перезапускайте Python. Для свободного общения нужен успешный ответ модели; без ключа интерфейс честно покажет локальный режим.
9. Коммитьте исходники в GitHub. **Не добавляйте `.env`, SQLite, резервную копию и свой экспорт профиля.**

Для полностью чистой демонстрации запустите отдельную базу, не удаляя существующую:

```bash
python3 server.py --port 8001 --db data/demo-v2.sqlite3 --public-origin https://ВАША-ССЫЛКА.trycloudflare.com
```

Чистая база включает синтетические подтверждённые требования и навыки. Для репетиции без очистки базы есть отдельный учебный пример в интерфейсе.

Если появился `Address already in use`, не запускайте второй экземпляр: найдите окно старого Python-сервера и остановите его Ctrl+C. Туннель останавливать не нужно.
