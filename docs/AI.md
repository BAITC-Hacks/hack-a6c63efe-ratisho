# AI: диалог, источники, навыки и объяснения

## Что делает модель

`ConversationAgent` получает исходное описание, текущие поля, сохранённые сообщения, память фактов и новый ответ. История хранится в SQLite, а не только в браузере. Модель отвечает на вопросы, учитывает предыдущие ответы, уточняет неопределённость и предлагает изменения памяти. В первом ответе нужны минимум три вопроса, затем один-два уместных уточнения. Изменения памяти не подтверждают поля и не начисляют рейтинг.

Каждый факт `{field, value, source}` содержит точную цитату из исходного описания или сообщения пользователя. Сервер отклоняет неизвестный источник, слишком длинное значение, несуществующее поле и текст, которого нет в источнике. Сообщения ассистента не являются доказательством. Исправление факта заменяет соответствующий элемент памяти, а исходная переписка остаётся. После сборки человек редактирует и подтверждает карточку. Проверка точного вхождения не гарантирует правильность смысловой классификации: поэтому ручная проверка обязательна.

При сборке карточки факты извлекаются из памяти, затем агент навыков автоматически предлагает до 12 навыков с цитатой-основанием и важностью 1–3. Новые требования не считаются согласованными до выбора бизнеса. Произвольные собственные навыки также можно добавить.

Review проверяет возможные противоречия. От модели принимаются до 6 замечаний с проверяемыми цитатами. Это гипотезы, а не утверждения о доказанной ошибке. После изменения карточки результат отмечен как устаревший; замечание можно отклонить или пометить исправленным.

Profile получает профессиональные выдержки GitHub / пользовательский текст. Навыки требуют источника и цитаты; достижения — точной выдержки. Затем участник проверяет список и выбирает достижения для показа. Рекомендация содержит эти выбранные выдержки и ссылки; новые достижения в саммари не генерируются.

## Контракты

Промпты доступны в исходниках: `CHAT_PROMPT`, `SKILLS_PROMPT`, `REVIEW_PROMPT` в `app/intelligence.py`, `PROFILE_PROMPT` в `app/profiles.py`. Базовые агенты Analysis, Interview, Composition и Validation сохранены в `app/agents.py`.

Пример ответа Conversation:

```json
{
  "reply": "Зафиксировал CSV за восемь недель. Кто будет пользоваться панелью?",
  "focus": "users",
  "updates": [
    {"field": "data", "value": "CSV за восемь недель", "source": "u-идентификатор-сообщения"}
  ]
}
```

Пример ответа Skills:

```json
{"skills":[{"name":"pandas","weight":2,"reason":"Может подойти для обработки таблиц","evidence":"CSV продаж"}]}
```

Все входные описания и профили трактуются как данные, а не инструкции. У модели нет инструмента публикации, выбора кандидата или изменения рейтинга. Секрет API остаётся в серверной конфигурации.

## Память и ограничения

До 200 сообщений / 100 000 символов на задачу. При лимите новые сообщения отклоняются с понятным ответом; старые остаются. Для каждого запроса модель получает сохранённую историю и карту фактов. Это явная история в JSON-входе Chat Completions, а не память аккаунта ChatGPT. После изменения `.env` нужен перезапуск сервера.

Удалённые вызовы используют JSON mode, проверку структуры и цитат, лимит размера, общий тайм-аут и ограничение параллельных вызовов. Некорректный ответ / отсутствие ключа / ошибка провайдера приводит к локальному режиму с предупреждением. Локально доступны вопросы по недостающим полям, явный выбор поля для ответа, словарь навыков и ограниченная проверка противоречий. Свободное рассуждение без модели не имитируется.

## Совместимость и объяснение

Расчёт детерминированный: доля покрытого веса подтверждённых навыков. Требования в черновике предложений модели не участвуют. Словарь нормализует эквивалентные названия (`powerbi` → `Power BI`), но не подменяет разные технологии (например, PostgreSQL не означает владение всеми SQL-инструментами автоматически). Результат — показатель полноты совпадения заявленного профиля, не прогноз качества работ.

В интерфейсе объясняются совпавшие навыки, отсутствующие сведения, совпадение интереса и источники достижений. Само объяснение расчёта строится из фактов без дополнительного вызова модели. Рейтинг готовности задачи и баллы за этапы независимы. Автоматическое назначение исполнителя отсутствует.

## Импорт

GitHub читается только через фиксированный `api.github.com`; URL профиля преобразуется в валидированный username. Произвольные URL, редиректы, приватные репозитории и форки не читаются. Просматриваются до 100 недавно обновлённых репозиториев, в профиль включаются до 12 оригинальных. Анализируются описания, темы и основной язык — не полный аудит кода. Кеш действует час. Публичный API без токена имеет ограничения частоты; ошибки и отсутствие сети показаны пользователю.

У LinkedIn Profile API ограниченный доступ. В этой сборке ссылка LinkedIn служит источником, анализируется текст, который предоставил сам участник (вставка или TXT/CSV/JSON). OAuth LinkedIn и прямое скачивание страниц не реализованы. PDF автоматически не разбирается: из него можно скопировать текст. Импорт не подтверждает владение аккаунтом.
