# Проверка перед передачей

Дата: 23 сентября 2026. Среда: macOS, Python 3.9.6, Node.js 24.19.0 для проверки синтаксиса JavaScript, встроенный браузер Codex.

## Автоматические проверки

Команда `python3 -m unittest discover -s tests -v`: **57 тестов прошли**.

- 24 проверки агентов и AI-провайдера: структура, минимум три вопроса, отсутствие выдуманных полей, сохранение человеческих ответов, проверка источников, невалидный JSON, тайм-аут и локальный резервный режим. Внешние ответы имитируются тестами.
- 23 проверки предметной логики и данных: веса, границы уровней, все 512 комбинаций подтверждений, пустые/неподтверждённые значения, лимиты полей, безопасные ссылки и минимальные объёмы исходных наборов.
- 10 HTTP-проверок с временной SQLite-базой: полный сценарий, публикация с 0 баллов, шесть откликов без лимита, две выбранные команды, ручной отказ, защита ролей и черновиков, конфликт редакций, сохранение, проверка данных и конкурентное однократное начисление +10.

`node --check static/app.js`: синтаксических ошибок нет. Модули Python успешно компилируются.

GitHub Actions настроены на Python 3.9, 3.12 и 3.13 в Ubuntu и Windows. Эти облачные задания ещё не запускались: они выполнятся после загрузки в репозиторий.

## Пройдено в браузере

1. Каталог: 5 исходных карточек в порядке 100 / 85 / 65 / 40 / 35; фильтр по отрасли оставил карточку теплицы, сочетание с несовместимым уровнем показало пустое состояние, сброс вернул список.
2. Создана новая задача о списаниях выпечки; получены 10 вопросов, локальный режим явно указан.
3. Введены ответы, собрана редактируемая карточка: рейтинг 0 до подтверждения.
4. Подтверждены 9 оцениваемых полей, после сохранения рейтинг 100.
5. Изменено поле данных: его подтверждение снялось, после сохранения рейтинг снизился до 80.
6. После отдельного ручного подтверждения задача опубликована.
7. В режиме команды отправлено предложение с идеей, планом, сроком и ссылкой; в режиме бизнеса команда выбрана вручную.
8. Выбранная команда отправила этап; бизнес подтвердил его, начислено 10 баллов.
9. После перезагрузки баллы сохранились и отображаются в профиле команды.
10. В просмотренных экранах нет ошибок и предупреждений в журнале браузера. Каталог и профили проверены визуально на ширине окна 1100 px.

Тестовая база браузерного прогона в архив не включена. При первом запуске из архива создаются исходные синтетические данные.

## Границы проверки

Реальный внешний AI API не вызывался: пользовательский ключ не предоставлен. Запуск без ключа, формат запросов, валидация ответов и резервный режим проверены. Авторизация промышленного уровня, нагрузочное тестирование и аудит безопасности не входят в ТЗ; роли переключаются для демонстрации. Это проверенный MVP, а не гарантия отсутствия любых возможных дефектов.
