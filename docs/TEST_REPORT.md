# Проверка HackAlem 2.0

Дата: 23 сентября 2026. Среда: macOS, Python 3.9.6, Node 24.19.0.

## Автоматические проверки

- **81 тест Python — прошли.** 57 базовых и 24 новых проверки v2.
- **6 тестов JavaScript-фильтрации — прошли.**
- Синтаксис `static/app.js`, `static/catalog.js` и компиляция Python — без ошибок.
- CI настроен на Python 3.9/3.12/3.13, Ubuntu/Windows и Node 22. Эти удалённые комбинации локально не запускались; результат появится после push в GitHub.

Проверены базовый сценарий ТЗ и точные границы рейтинга; независимость прогресса и готовности; ручной выбор нескольких команд; сохранение памяти в SQLite; отсутствие автоматического подтверждения; замена факта при исправлении; повторное уточнение неизвестного; передача всей истории провайдеру; отклонение фактов без цитаты и цитат из сообщений ассистента; согласование навыков и веса; различная совместимость одного профиля с разными задачами; отсутствие оценки при несогласованных требованиях; проверка противоречий и решения по замечаниям; автоматическое предложение навыков после сборки карточки; приватность предварительного импорта относительно других демо-ролей; версия профиля и задачи; HTTPS Origin; ограничения URL для GitHub; исключение форков и кеш; выбор достижений; сохранность обычных задач при сбросе учебного примера.

Фильтры: пересечение тематики, навыков, рейтинга, совместимости и даты; несколько значений внутри группы; режим «все навыки»; пересчёт счётчиков по остальным фильтрам; пустой результат и сброс; отсутствие скрытия низкого рейтинга по умолчанию; точные границы дат; неподтверждённые навыки не участвуют.

## Проверено в браузере

1. Загрузка нового каталога и страниц создания/профиля.
2. Создание задачи → начальные три вопроса → два ответа с изменением темы.
3. История и оба факта сохранились после обновления страницы.
4. Карточка собрана из ответов; ручное подтверждение трёх полей подняло рейтинг с 0 до 40.
5. Предложены pandas и Power BI; до выбора они не считались требованиями. После подтверждения бизнесом появились в карточке.
6. Публикация; бизнес видит кандидатов с совместимостью 100%, 50%, 0% и объяснениями по согласованным навыкам.
7. Переключение на студента, текстовый импорт учебного профиля, предварительный список навыков, отдельное подтверждение и сохранение.
8. Каталог в роли студента показывает разные оценки для разных задач. Совместный выбор двух тематик и Power BI оставил только пересечение; счётчики обновились.
9. Визуально просмотрены каталог и переписка. Полная проверка всех мобильных размеров не проводилась.

## Внешние интеграции и границы

- Живой запрос публичного GitHub API для тестового публичного аккаунта `octocat` прошёл: получены 6 подходящих источников. Пользовательские профили и секреты при тестах не использовались.
- Новые ответы языковой модели проверялись управляемыми ответами провайдера: корректные источники, галлюцинации, ошибочная структура, отказ и резервный режим. **Живые платные запросы с ключом команды не выполнялись.** Качество свободного диалога на выбранной реальной модели нужно проверить после настройки `.env`.
- LinkedIn URL автоматически не скачивается: проверен импорт предоставленного текста, без OAuth и обхода ограничений.
- Постоянный внешний хостинг не развёрнут. Поддержка точного публичного HTTPS Origin протестирована; ранее созданный туннель команды остаётся отдельным процессом.
- Dockerfile добавлен как вариант запуска; сборка Docker-образа в этой среде не выполнялась.
- Из чистой распаковки финального архива повторно прошли 81 тест Python и 6 тестов JavaScript. Архив не включает ключи, базу, профили, историю чата и браузерные тестовые данные. В проверенной браузерной сессии ошибок и предупреждений JavaScript не обнаружено.
