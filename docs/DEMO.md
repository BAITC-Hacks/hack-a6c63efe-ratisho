# Демонстрация до пяти минут

Все числа и контакты ниже синтетические. Откройте приложение заранее. Для чистой демонстрации запустите с новой базой: `python3 server.py --db data/defense.sqlite3`.

## 0:00–0:30 · Слабое описание

Роль «Бизнес», новая задача, тема «Общественное питание»:

> У нас кофейня, часто списываем выпечку. Нужно понятнее планировать количество на завтра.

Получите вопросы. Покажите не менее трёх уместных вопросов. Обратите внимание на честную метку локального / внешнего AI-режима.

## 0:30–1:45 · Карточка и рейтинг

Подготовленные ответы для быстрого ввода:

| Поле | Ответ |
|---|---|
| Название | Планирование выпечки для кофейни |
| Контекст | Управляющий вручную определяет количество выпечки, вечером остаётся непроданная продукция. |
| Потребность | Планировать выпечку по продажам и остаткам. |
| Пользователи | Управляющий кофейней и пекарь. |
| Данные | Есть синтетический CSV продаж, остатков и списаний за восемь недель. |
| Ограничения | Прототип за семь дней; без подключения к кассе. |
| Результат | Веб-экран загрузки CSV и редактируемый план выпечки на завтра. |
| Критерии успеха | Импорт 100 строк без потерь, суммы совпадают с контрольной таблицей. |
| Контакт | Учебный куратор: demo@example.com. |
| Взаимодействие | Две консультации по двадцать минут за неделю. |

Для краткой защиты заполните часть ответов, остальные добавьте в редактируемой карточке. Покажите: до подтверждения — 0; подтверждение известных полей увеличивает рейтинг; добавление данных даёт ещё 20 баллов. Рейтинг соответствует видимой расшифровке. Итоговые 100 не обязательны для публикации.

## 1:45–2:20 · Публикация и общий каталог

Подтвердите публикацию. Покажите задачу в каталоге и сортировку по рейтингу. Один раз включите и сбросьте фильтр. Укажите карточку с низким рейтингом: она тоже доступна для откликов.

## 2:20–3:10 · Отклик команды

Переключитесь в «Команда», выберите профиль, откройте новую задачу.

- Идея: «Сделаем веб-панель по истории продаж».
- План: «Импорт CSV, сводка остатков, проверка на контрольных данных».
- Срок: «Семь дней».
- Ссылка: `https://example.com/demo-prototype` — демонстрационная ссылка.

Отправьте предложение. Оно получает статус ожидания, команда не назначается автоматически.

## 3:10–4:10 · Решение бизнеса

Вернитесь в «Бизнес». Откройте предложения и выберите команду вручную. Если нужно показать сравнение, используйте существующую карточку с несколькими заранее загруженными откликами. Можно выбрать несколько команд или отклонить все.

## 4:10–4:45 · Подтверждённый этап

В режиме выбранной команды отправьте учебный этап «Первый прототип», ссылку `https://example.com/demo-result`. В режиме бизнеса подтвердите этап. Баллы команды увеличатся на 10. Отдельно назовите это подготовленным демонстрационным результатом, а не работой, выполненной за время выступления.

## 4:45–5:00 · Сдача

Покажите репозиторий, README с запуском и результат тестов. Все переходы демонстрируются в приложении, слайды не нужны.
