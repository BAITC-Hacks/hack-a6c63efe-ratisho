# Демонстрация до 5 минут

Перед показом проверьте модель на одном запросе. Если она недоступна, честно покажите резервный режим и промпты в `docs/AI.md`. Не вводите секреты в описание задачи или профиль.

1. **0:00–0:40.** Бизнес → Репетиция демо → создать учебный пример. Объясните: кофейня хочет снизить списания, пока задача неполная.
2. **0:40–1:40.** Начните диалог. Сообщите: управляющий, CSV продаж за восемь недель, прототип за семь дней. Уточните одну деталь следующим сообщением; покажите память и сохранение переписки после обновления.
3. **1:40–2:30.** Соберите карточку. Подтвердите известные сведения; покажите рост рейтинга. Выберите измеримый критерий, например обработку 100 тестовых строк без потерь. Сохраните.
4. **2:30–3:20.** Согласуйте pandas и Power BI, покажите веса. Проверьте возможные противоречия, опубликуйте вручную. Панель агентов показывает реальные завершённые этапы и режим модели.
5. **3:20–4:10.** Переключитесь на Data Sprout. В каталоге выберите несколько фильтров: тему, навыки, минимум готовности, сортировку по совместимости. Покажите, почему задача подходит. Отправьте отклик с идеей, планом, сроком и URL.
6. **4:10–5:00.** Бизнес: таблица откликов, подходящие профили и объяснение. Выберите вручную. Если осталось время, команда отправляет этап, бизнес подтверждает +10.

Импорт GitHub и текст LinkedIn лучше подготовить до выступления; покажите согласованный профиль, выбранные достижения и источники. При отсутствии сети не выдавайте сохранённый пример за новый сетевой запрос.

Сброс в «Репетиции демо» затрагивает только специальный учебный пример и его отклики; основные задачи и профили сохраняются. Полностью чистые данные можно получить через отдельный `--db data/demo-v2.sqlite3`.
